02 / 找谁

合作是双向选择

$ grep -r 适合 .

先说清楚我能帮到谁、帮不到谁——这一步能替我们省下很多时间。看完你觉得对得上，再往下翻。

我们大概率合得来

如果你是这样的，往下聊基本不会错：

  • +手里有业务——已经摸到真实需求：有客户、有会员、有每天在发生的事，只是被效率卡着脖子。
  • +有想法、没技术——说得清要解决谁的问题，只是不知道怎么做出来。
  • +第一版已经在跑——有个糙但能用的东西，需要有人长期接手，把它养大。
  • +小团队——5–20 人，养不起技术团队，但需要技术像自己人一样靠得住。
  • +行动派——想验证就动手，不等「完美方案」，也接受先做 60 分。

这些我帮不了

不是瞧不上，是真的不匹配——早点说清楚对彼此都好：

  • −只想比价——第一句话是「做个小程序多少钱」，那我们都会浪费时间。
  • −想一步到位——要一次做完所有功能的「完美产品」，我劝不住，也不劝。
  • −还没想清楚为谁做——只有一个「平台梦」，说不清第一个用户从哪来。
  • −中介转包——拿我的报价去赚差价的，直接免谈。
  • −拿融资讲故事——聊的全是三年后的故事，不聊下个月的用户。

04 / 投入

三种合作方式

// 不按小时计费，不做报价拉锯

对应合作的三个阶段。都从最小的一步开始——走不走得下去、走到哪一步，随时由你决定，每个阶段结束都是自然的退出点。

$ git checkout -b mvp

MVP 冲刺

2–4 周 · 按阶段一口价
  • 核心流程跑通，只做验证必须的功能
  • 部署上线：域名、服务器、小程序审核
  • 两轮修改：真实用户用完之后的调整
  • 一页纸交接文档，写给三个月后的你
开工前范围和价格都锁定，没有隐性收费。适合「想法刚落地，想先试试水」。
80% 的合作在这里 $ git merge --continue

长期同行

按月 · 最短 3 个月 · 不押金
  • 每周都有可见的进展，不用追着问
  • 需求随聊随排，不写文档不走流程
  • 线上问题响应，服务器告警我盯着
  • 每月一次数据复盘：什么该做、什么该砍
比养一个初级程序员便宜，比外包驻场靠谱——这是伙伴们的原话。适合「已有用户，要持续迭代」。
$ git remote add 我们

深度合伙

长期 · 用代码换少量股份
  • 我投入开发，你保留业务的全部主导权
  • 不占工资，只在产品赚钱之后分成
  • 仓库、账号、文档从第一天就在你名下
  • 每年最多 1 个名额，聊透才谈
只投给「已经有人付费」的方向——空想法不换股份，这是底线。

每种模式，怎么执行、怎么付钱、怎么退出？

周期、付款节点、报价逻辑、变更与退出条款——都摊开写在执行手册里，价格按手作坊来。

05 / 流程

从一个想法，到有人付费

// 五条命令，跑完一个闭环
$ git init

你带着想法来

不用需求文档。一次语音、几张截图，或者一句「我想做个 XXX」，就能开工。

一页纸的范围共识，当天定稿
$ git checkout -b mvp

两周出第一版

只做核心流程的最小闭环：能跑、能给真人用。其余的，一律先不写。

一个能点的链接 + 测试账号
$ git commit

交给真实用户

第一版直接面对用户。反馈回来的每一条，都会变成下一次提交。

每周一次的可见迭代
$ merge 主线

验证后加大投入

跑通了就补体验、补安全、补那些「早晚要还」的技术债，把它变成正经产品。

稳定版 + 补齐的底子
$ git push

一起持续迭代

上线不是结束。产品每长大一点，我们的合作就多一个 commit。

08 / whoami

写代码的，也是担责任的

$ cat 关于我.txt

我是独立全栈开发者，写了 8 年代码。过去三年，我把自己当成六家初创团队的「编外技术合伙人」——不占股份的名分，但占那种责任。

每一段合作都从同一个问题开始：「你想让谁，在什么场景下，因为什么付费？」答得上来，我们就从 MVP 干起；答不上来，那就先一起把问题聊清楚——这一步不要钱。

  • 2017–2020

    在软件公司写业务系统。见过太多「交付那天就是项目死亡之日」的合同，开始琢磨另一种合作方式。

  • 2020.08

    开始独立。第一单是帮朋友的婚礼工作室做小程序，收了 3000 块改了 11 版——没人抱怨，因为他每次提需求，第二天就能看到东西。

  • 2023.03

    课表通上线。第一次明白「陪跑」的意思：产品的每一步，都跟着业务的呼吸走。

  • 2024.10

    选题库开始收费。第一次和伙伴一起，把自用的工具卖给了同行。

  • 2025.12

    六段合作并行。学会了说不——深度比数量值钱。

  • 2026

    现在，等你这一段。

$ 原则一 / 不转包你对接的永远是写代码的本人。出了问题没有中间商，没有「我问下我们团队」。
